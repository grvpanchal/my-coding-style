my-coding-style

A minimal Node.js template — ESLint airbnb-base plus a five-command agent-skills flow for AI-assisted development.

The Flow

Five slash commands in Claude Code, run in order. Skip what doesn't apply.

/spec Define
/plan Plan
/build Build
/review Review
/ship Ship

What Each Command Does

  • /spec Turn a vague idea into a structured SPEC.md covering objective, features, and boundaries. → spec-driven-development
  • /plan Decompose the spec into vertical-slice tasks with acceptance criteria and dependency ordering. → planning-and-task-breakdown
  • /build Implement the next task incrementally with TDD. Debug if anything breaks. → incremental-implementation, test-driven-development, debugging-and-error-recovery
  • /review Five-axis review: correctness, readability, architecture, security, performance. → code-review-and-quality
  • /ship Parallel fan-out to three personas, then a single go/no-go decision with a rollback plan. → shipping-and-launch

Specialist Personas

Spawned in parallel by /ship for an independent read.

code-reviewer security-auditor test-engineer

Project Layout

.claude/
├── skills/        # 7 lifecycle SKILL.md files
├── commands/      # 5 slash commands
└── agents/        # 3 specialist personas
CLAUDE.md          # project conventions for Claude
.editorconfig     # 2-space, UTF-8, LF
.eslintrc.js      # airbnb-base + overrides
index.js          # entry point
index.html        # this page

Code Style

Extends airbnb-base. Project overrides live in .eslintrc.js: 

module.exports = {
  extends: 'airbnb-base',
  rules: {
    'no-undef': 'off',
    'no-alert': 'off',
    'quote-props': 'off',
    'brace-style': 2,
    'object-shorthand': 'off',
    'no-console': 'off',
  },
};

Run It

npm install
npm start          # node ./
npx eslint .       # lint
